# Пошук математичних інваріантів

## Workflow

1. Specify the transformation or dynamics and candidate quantity.
2. Derive preservation through equations or structural identities.
3. Check domains, discontinuities and boundary contributions.
4. Distinguish invariants, monotone quantities and approximately conserved numerics.
5. Test candidates on counterexamples and state proved scope.

## Evidence discipline

State exact hypotheses and domains; separate proof, conjecture, observation and conditional result. Verify external theorem assumptions and source locators. Do not invent citations, novelty or tool outcomes. Use the user’s language. Read the decision guide and acceptance cases before completing work; load neighboring skills only when needed.
