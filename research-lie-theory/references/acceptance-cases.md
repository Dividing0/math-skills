# Acceptance cases

## Representative request
Does an isomorphism of Lie algebras imply an isomorphism of Lie groups?

## Required behavior
Separate local structure from global topology; inspect distinct groups with the same Lie algebra.

## Transfer case
Remove an essential hypothesis from a theorem in this area. Identify exactly which proof step loses justification, search for a counterexample, and label the proposed extension as unproved unless every obligation is discharged.
